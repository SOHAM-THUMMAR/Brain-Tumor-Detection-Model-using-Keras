4. Figure 4.2: High-Level System Class Architecture Diagram
UML Class Architecture depicting Config, Application Factory, Controller Blueprints, and Service Layer Singletons.
classDiagram
    direction TB

    class Config {
        +str BASE_DIR
        +str MODEL_PATH
        +tuple IMG_SIZE = (224, 224)
        +set ALLOWED_EXTENSIONS
        +int MAX_FILE_SIZE_MB = 10
        +float CLASSIFICATION_THRESHOLD = 0.3
    }

    class ApplicationFactory {
        +create_app(config_class) Flask
    }

    class PredictRoutes {
        +handle_predict() HTTPResponse
        +download_report(filename) HTTPResponse
    }

    class ValidationService {
        +is_allowed_file(filename) bool
        +is_valid_file_size(file_path) bool
    }

    class ImageService {
        +preprocess_image(image_input) tuple
    }

    class ModelService {
        -_MODEL_INSTANCE
        +load_model() Model
        +predict(model, img) tuple
    }

    class GradCAMService {
        +generate_gradcam(...) tuple
    }

    class PDFService {
        +generate_patient_pdf_report(...) str
    }

    ApplicationFactory ..> Config : uses
    ApplicationFactory --> PredictRoutes : registers blueprint
    ApplicationFactory ..> ModelService : pre-loads model singleton

    PredictRoutes ..> ValidationService : validates
    PredictRoutes ..> ImageService : resizes/normalizes
    PredictRoutes ..> ModelService : infers
    PredictRoutes ..> GradCAMService : visual overlays
    PredictRoutes ..> PDFService : generates PDF

6. Section 4.8.3: Control Flow Diagram (CFD)
Control Flow Diagram mapping execution states, decision predicates, exception branches, and threshold branching.
flowchart TD
    Start(["App Boot: load_model()"]) --> CheckModel{"bestModel.keras Exists?"}
    CheckModel -- No --> ErrModel["Raise FileNotFoundError & Abort Startup"]
    CheckModel -- Yes --> Listen["Listen for Client Requests"]
    
    Listen --> RecvReq["Receive HTTP POST multipart/form-data"]
    RecvReq --> CheckPart{"file in request.files?"}
    CheckPart -- No --> Err400_1["Return HTTP 400: No File Part"]
    CheckPart -- Yes --> CheckExt{"is_allowed_file (.png, .jpg)?"}
    CheckExt -- No --> Err400_2["Return HTTP 400: Invalid Extension"]
    CheckExt -- Yes --> SaveDisk["Save File to app/static/uploads/"]
    
    SaveDisk --> CheckSize{"is_valid_file_size (max 10MB)?"}
    CheckSize -- No --> DelFile["Remove Uploaded File"]
    DelFile --> Err400_3["Return HTTP 400: File Too Large"]
    CheckSize -- Yes --> Preproc["preprocess_image (RGB 224x224, /255.0)"]
    
    Preproc --> PredictPass["model.predict feedforward pass"]
    PredictPass --> EvalThresh{"Probability >= 0.3 Threshold?"}
    EvalThresh -- Yes --> TumorBranch["Set Label = 'Tumor', Conf = prob * 100%"]
    EvalThresh -- No --> NoTumorBranch["Set Label = 'No Tumor', Conf = (1 - prob) * 100%"]
    
    TumorBranch --> GradCAMPass["tf.GradientTape Autograd Pass & Otsu Head Mask"]
    NoTumorBranch --> GradCAMPass
    
    GradCAMPass --> CheckTumorVis{"Label == 'Tumor' AND max_focus > 30?"}
    CheckTumorVis -- Yes --> DrawHUD["Isolate Top 50% ROI, Draw Crimson Fill & HUD Box"]
    CheckTumorVis -- No --> CleanScanBadge["Draw Clean Scan Status Badge"]
    
    DrawHUD --> BuildPDF["generate_patient_pdf_report (ReportLab PDF Build)"]
    CleanScanBadge --> BuildPDF
    
    BuildPDF --> RenderRes["Render result.html Dashboard View"]
    RenderRes --> DownloadCheck{"Client clicks Download Report?"}
    DownloadCheck -- Yes --> StreamPDF["Stream PDF Attachment Download"]
    DownloadCheck -- No --> Idle(["System Ready for Next Upload"])
